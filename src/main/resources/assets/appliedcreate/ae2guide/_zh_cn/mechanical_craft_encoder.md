# 动力合成编码器

<Row gap="20">
<Column>

<ItemImage id="appliedcreate:mechanical_craft_encoder" scale="4" />

动力合成编码器是一个实用方块，用于查阅机械动力的动力合成配方，帮助你了解自动化所需的材料布局。

</Column>
</Row>

## 工作原理

动力合成编码器提供了一个GUI界面，你可以在其中浏览所有已注册的动力合成配方。对于每个配方，它会显示：

- **配方产物** — 该配方合成的物品
- **材料网格** — 材料在正确位置上的精确布局，包括空槽位
- **网格尺寸** — 合成所需的网格形状

这些信息对于创建与 <ItemLink id="appliedcreate:andesite_pattern_provider" /> 或 <ItemLink id="appliedcreate:brass_pattern_provider" /> 配合使用的AE2处理样板至关重要。

## 使用方法

1. **放置**动力合成编码器
2. **右键点击**打开GUI界面
3. **浏览**可用的动力合成配方
4. **记录**材料布局和网格形状
5. **创建**与配方输入输出匹配的AE2处理样板

## 提示

- 编码器是一个查阅工具 — 它不会消耗或产出任何物品
- 配合AE2样板终端使用，创建匹配的处理样板
- 注意网格布局 — 动力合成器要求材料放置在特定位置
- 网格中的空槽位很重要，必须在动力合成器阵列中保持为空
