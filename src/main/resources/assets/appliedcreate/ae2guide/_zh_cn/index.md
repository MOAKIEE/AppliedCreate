# 应用机动

应用机动将 [机械动力](https://www.curseforge.com/minecraft/mc-mods/create) 的动力系统与 [应用能源2](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2) 的自动化系统连接起来。

它引入了专用的样板供应器、应力存储元件、动力P2P通道以及能量转换方块，实现两个模组的深度联动。
